# 版本更新

## v1.6.0 · 关山粮道

- 加入秦岭关、西岭隘，两处关隘分别提供35%、15%的地块防御加成。
- 加入四处粮道驿站：驻站正常休整额外恢复10生命，从完整驿站开始回合时移动力+1。
- 驿站可劫掠、修复，加入军道图志和路线示意。
- 升级关隘、粮道及劫掠状态的像素图标，提供彩色设施头像。
- 美化城池领地外围边界，改善通知栏背景与文字的对比度。
- GitHub公开版整理安装说明，并统一情景、地图和备用存档的模组名称，适配游戏内下载。

## v1.5.0 · 将略与军议

- 四位名将各有两条、每条两阶的专属晋升路线，共16项；两条路线互斥。
- 新开局名将拥有10经验，韩信每个本方回合结束获得1统军经验。
- 玩家势力可在第8、20、35回合起，或完成上一章后夺城，依次召开三次中途军议。
- 军议可选择募兵、整军或补充军资；进度随存档保存，同章不可重复领取。
- 加入专属晋升徽章、军议插图和中文方案说明。

## v1.4.0 · 城池争夺

- 七座城市各有特色设施，分别强化财政、生产、补给、城防、训练或骑兵。
- 特色设施随城池转交，不能建造、购买或出售。
- 加入城邑军情提示。
- 修复Scenario选择雍、塞、翟后仍进入汉国回合的问题。

## v1.3.0 · 名将出秦

- 加入韩信、樊哙、曹参、章邯四位名将及像素头像、地图单位。
- 提供标准、缓冲两个完整Scenario，包含预设城市、军队与固定战事。
- 修复模组识别和开局部署问题。
- 清理旧开局、重复文件、测试资料与旧启动器。

完整体验新版内容，请从v1.6.0 Scenario重新开始。图标与界面更新可用于已有进度；旧版手动安装存档需保留其依赖的原模组目录。
